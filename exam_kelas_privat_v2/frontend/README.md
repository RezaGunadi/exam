# Frontend Next.js

Frontend ini memecah migrasi per tema halaman:

- `login` / `register`
- `dashboard`
- `admin/*` untuk master data, ujian, hasil, absensi, tugas, tutor
- `student/*` untuk ujian, result, tugas
- `referrals`

## Menjalankan

```powershell
copy .env.example .env.local
npm install
npm run dev
```
